# Private preparation and eventual public release

## Prepared here

- Frozen first-experiment observations, scores, all selected campaign attempts and hashes.
- Portable offline reproduction; expected values match the local camera-ready paper.
- Original figure sources and citation metadata without invented publication DOI.
- Actor/evaluator separation and limitations documented.
- Generated bytecode and the deleted proposal removed from the current agent index.
- Later unpublished local files excluded from staging.
- Clean source exporter omits Git history, proposal, local secrets and unrelated preflight files.

## Decisions before publishing

1. Finalize the code license and separately scoped dataset/output permissions in `LICENSING.md`.
2. Use the clean source export for a dedicated public artifact repository. The existing agent history still contains the proposal; a current-tree deletion does not remove historical copies. No history rewrite is authorized or performed by this preparation.
3. Run the reproduction command from a fresh checkout/extracted export. CI also runs the offline checks.
4. Create the actual release/tag and, if desired, a persistent artifact DOI; update `CITATION.cff` and the paper's availability statement with verified identifiers.
5. Add final volume/pages/publisher DOI when supplied. Acceptance is not a substitute for those metadata.

Keep the original experimental archive immutable. Corrections belong in a new artifact version with an explanation. Do not publish confidential reviewer correspondence or assume the final publisher PDF has the same sharing terms as software and data.
